SB 360 VERSION 2.0 – FREE STARTER

FILES:
- index.html: Main application
- manifest.webmanifest: Installable web app settings
- sw.js: Offline cache
- icons/: App icons

GITHUB UPDATE (MOBILE):
1. ZIP ko extract karein.
2. Repository ke Code tab par jayein.
3. Add file > Upload files chunein.
4. Is folder ke andar ki files/folders upload karein. ZIP ko direct upload na karein.
5. Existing index.html, manifest.webmanifest aur sw.js ko replace/overwrite karein. icons folder ke dono PNG upload karein.
6. Commit changes karein.
7. 2-5 minute baad https://YOUR-USERNAME.github.io/sb360/ kholen.
8. Chrome me Install app ya Add to Home screen chunein. Agar Install disabled ho to pehle Create shortcut use kar sakte hain; PWA install eligibility ke liye files root par aur HTTPS par honi chahiye.

FEATURES:
- Dashboard
- Loan and EMI register (estimated outstanding only)
- Personal income and expense register
- Task list with assignee, due date, priority and status
- JSON backup and restore
- Responsive mobile/computer interface
- PWA manifest and offline cache

IMPORTANT LIMITATIONS:
- This is a free, single-device/browser prototype. It has NO user login, NO cloud database, NO multi-user sync and NO secure server-side access control.
- Data is stored in browser localStorage. Clearing browser data may erase records. Export JSON backups regularly.
- Do not store passwords, full bank account numbers, identity numbers or highly confidential records.
- Loan outstanding is an approximate estimate and not a bank payoff/foreclosure quote. Verify with lender statements.
- This version does not automatically make payments or send reminders.
