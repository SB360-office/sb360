SB 360 – Starter update

Upload the CONTENTS of this folder to the ROOT of your existing GitHub repository, replacing existing files. Keep the icons folder. Commit the changes.

This starter includes Dashboard, Tasks, Loan Register, Personal Finance, starter Project and Team pages, and JSON Backup/Restore for local records.

Important: data remains only in the current browser/device. There is no secure login, shared cloud database, multi-user sync, or server backup yet. Do not enter bank passwords, full account numbers, identity numbers, or confidential data. Never upload private backups to your public GitHub repository.
