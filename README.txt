SB 360 PWA Starter

This folder is a Progressive Web App package. To install it on Android, it must be hosted over HTTPS (for example GitHub Pages or Netlify). Opening index.html directly from a ZIP/file manager will NOT show Install app.

Free hosting quick path (GitHub Pages):
1. Create/sign in to a GitHub account.
2. Create a new public repository named sb360.
3. Upload ALL files and folders from this folder (index.html, manifest.webmanifest, sw.js, icons/).
4. In repository Settings > Pages, choose Deploy from a branch, branch main, folder /(root), then Save.
5. Wait for the Pages URL to appear, open it in Chrome on Android.
6. Chrome menu (three dots) > Install app or Add to Home screen.

Important: Current prototype stores records in the browser's local storage on one device only. It has no user login, cloud sync, or secure multi-user database yet. Do not enter sensitive banking credentials or confidential data.
